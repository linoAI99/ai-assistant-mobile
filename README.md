# AI Assistant Mobile - Self-Hosted AI Chat App

A futuristic, lightweight, self-hosted AI interactive assistant for mobile devices, optimized for Infinix Smart 8 and other Android devices with minimal hardware requirements.

## 🌟 Features

- **Multi-Model Support**: Switch between Qwen 3 (8B/27B), Kimi K3, and SpaceX Grok AI
- **Lightweight & Optimized**: Minimal resource consumption, optimized for low-end devices
- **Dark Theme UI**: Modern, futuristic interface with custom theming
- **No Internet Required**: Fully self-hosted, runs locally on your device
- **Free & Open-Source**: Uses only open-source models from HuggingFace
- **Responsive Design**: Seamless experience on various screen sizes
- **Zero Cost**: No API fees, no subscriptions, completely free

## 📱 Target Device

- **Primary**: Infinix Smart 8 (and similar low-end Android devices)
- **OS**: Android 8.0+
- **RAM**: 4GB+ recommended
- **Storage**: 5GB+ available space

## 🚀 Supported AI Models

1. **Qwen 3 (8B)** - Lightweight, fast inference
2. **Qwen 3 (27B Max)** - Advanced capabilities, requires 8GB+ RAM
3. **Kimi K3** - Optimized for mobile devices
4. **SpaceX Grok AI** - Latest open-source alternative

## 📋 Project Structure

```
ai-assistant-mobile/

```

## 🛠️ Tech Stack

- **Frontend**: Kotlin (Android Native)
- **Backend**: Local inference engine
- **Models**: ONNX Runtime, TensorFlow Lite
- **UI Framework**: Material Design 3
