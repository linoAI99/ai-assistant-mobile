# Contributing to AI Assistant Mobile

## Code of Conduct

Be respectful, inclusive, and constructive in all interactions.

## How to Contribute

### Reporting Bugs

1. Check if the bug already exists in Issues
2. Create a detailed bug report with:
   - Device model and Android version
   - Steps to reproduce
   - Expected vs actual behavior
   - Logs/screenshots

### Proposing Features

1. Open an Issue with `[Feature]` prefix
2. Describe the feature and use case
3. Provide mockups/examples if possible

### Code Contributions

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Follow code style guidelines (Kotlin conventions)
4. Test thoroughly
5. Submit a Pull Request with detailed description

## Code Style

- Use Kotlin conventions
- Follow Android Architecture Components guidelines
- Document public APIs with KDoc
- Use meaningful variable names
- Keep functions small and focused

## Testing

Before submitting PR:
- Test on multiple Android versions
- Test on devices with varying RAM
- Check memory usage and performance
- Verify all models work correctly

## Development Setup

```bash
git clone https://github.com/yourusername/ai-assistant-mobile.git
cd ai-assistant-mobile
./gradlew build
```

## Questions?

Open a Discussion or Issue for questions and feedback.
